# Source and asset provenance

This repository selectively adapts benchmark files from the same owner's `callgideon/model-inference` repository at the commits listed in PROVENANCE.json. Publication was requested by the repository owner. No open-source license is invented for this code; a project-wide license remains the owner's choice.

Model and dataset manifests contain public metadata, exact revisions, download URLs and file checksums. Model weights and dataset rows are not redistributed in this checkpoint. Read each upstream license and access conditions before an authorized download or use. Model-card license labels are discovery metadata, not a legal review or permission grant.

The optional GSM8K source is `openai/grade-school-math`, revision `3101c7d5072418e28b9008a6636bde82a006892c`, MIT License, Copyright (c) 2021 OpenAI. Its license is linked in the manifest. Preserve the upstream copyright/permission notice with any subsequent redistribution of dataset content. The numeric-only transformation is an instruction-following task variant, not the official GSM8K evaluation.

Historical code and CPU fixtures do not transfer model/runtime qualification. Public documentation links can change; immutable checkpoint hashes and retained support reviews must be checked again before a real run.
